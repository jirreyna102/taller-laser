# Taller Láser · Sublimarte

App para operar el taller de grabado y corte láser ATOMSTACK A10 Pro V2: recetas y calibración, diseño paramétrico, vectorizador, producción, cotizaciones, inventario, rotatorio R6, operación y seguridad.

**Abrir e instalar:** https://jirreyna102.github.io/taller-laser/ (en Edge o Chrome, botón **Instalar**).

Funciona sin conexión y guarda los datos solo en tu computadora. Instrucciones completas en [LEEME.md](LEEME.md).
